# СанМедЭкспресс

Статический одностраничный лендинг для компании «СанМедЭкспресс»: перевозка лежачих больных и маломобильных людей 24/7.

## Что внутри

- `index.html` - структура страницы.
- `css/styles.css` - все стили, адаптивность и цветовые переменные.
- `js/main.js` - frontend-валидация формы и заготовка данных заявки.
- `assets/images/*.svg` - временные изображения-заглушки для будущих реальных фото.
- Bootstrap 5 подключен через CDN в `index.html` для меню, модального окна, сетки и FAQ-аккордеона.
- `Info/Что установить для проверки и редактирования.docx` - инструкция для локальной проверки и редактирования.

## Как открыть

Откройте `index.html` двойным кликом в браузере. Backend, база данных и сборка не нужны. Для полного отображения Bootstrap нужен интернет, потому что Bootstrap подключен через CDN.

На GitHub в обычном репозитории открывается `README.md`, а не сайт. Чтобы сайт был доступен по ссылке, включите GitHub Pages: `Settings` -> `Pages` -> `Deploy from a branch` -> ветка `main` -> папка `/root`.

## Что заменить позже

- Фото в `assets/images` на реальные фото транспорта и оснащения.
- Заглушку ссылки на Яндекс Бизнес / Яндекс Карты в блоке контактов.
- Ссылку MAX в блоке контактов, когда будет готова публичная ссылка профиля MAX.
- Ссылки-заглушки на политику конфиденциальности и согласие на обработку персональных данных.
- Отправку формы в `js/main.js`, когда появится backend или Telegram-бот.

## Какие фото нужны

- Автомобиль снаружи, чистый, при дневном свете.
- Салон автомобиля без людей, мусора и личных вещей.
- Носилки, каталка, кресло, ремни фиксации и другое оборудование.
- Сотрудники в форме, без пациентов и документов в кадре.
- Детали бренда: медицинский знак, наклейки на машине, номер телефона.
