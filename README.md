# СанМедЭкспресс

Готовый к эксплуатации сайт для службы медицинской транспортировки «СанМедЭкспресс»: прием заявок с лендинга, хранение обращений в базе, админка для обработки и автоматические уведомления ответственным сотрудникам.

## О проекте

Сайт помогает быстро принять заявку на перевозку лежачих больных и маломобильных людей. Пользователь оставляет имя, телефон и комментарий, после чего заявка сохраняется в системе и передается менеджеру через рабочие каналы уведомлений.

Интерфейс оформлен как доверительный медицинский сервис: спокойная визуальная подача, понятные преимущества, реальные фотографии, адаптивная верстка и юридические страницы.

## Возможности

- Лендинг с формой заявки и адаптивной версткой для компьютеров и смартфонов.
- Backend на Spring Boot для приема и обработки заявок.
- PostgreSQL для хранения клиентов и обращений.
- Админка с авторизацией, статусами заявок, карточкой обращения и экспортом в CSV.
- Email-уведомления о новых заявках.
- Telegram-уведомления с номером заявки для быстрого поиска в админке.
- Асинхронная отправка уведомлений после сохранения заявки в БД.
- Независимые каналы уведомлений: сбой email не блокирует Telegram, сбой Telegram не блокирует email.
- Production-логи по созданию заявок, смене статусов и отправке уведомлений.

## Архитектура

- Frontend: статический сайт на HTML, CSS и JavaScript.
- Reverse proxy/static serving: nginx.
- Backend: Spring Boot 3, Java 21.
- Database: PostgreSQL.
- Migrations: Flyway.
- Admin UI: Thymeleaf + Spring Security.
- Deployment: Docker Compose.

## Надежность

Заявка считается успешно принятой после сохранения в базе данных. Отправка email и Telegram выполняется отдельно, в фоне и после commit транзакции, поэтому внешние сервисы не влияют на ответ пользователю формы.

Для SMTP и Telegram настроены сетевые таймауты. Ошибки каналов уведомлений не пробрасываются наружу и фиксируются только в backend-логах.

## Безопасность

- Доступ к админке защищен Basic Auth.
- Секреты и реальные токены хранятся вне репозитория.
- Telegram token и SMTP password не выводятся в логи.

## Статус

Проект готов к эксплуатации: сайт, backend, база данных, админка, email и Telegram-уведомления настроены и работают через Docker Compose.
